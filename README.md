# 基金从业资格考试练习站（科目一＋科目三）

基于本人 [tccp-practice](https://github.com/supernc/tccp-practice) 架构改造。科目一保留本机旧题 985 道，**尚未按2026大纲逐题复核，原始题库也未附可核验的网页出处**；科目三新增 110 道按 2026 年大纲原创的概念练习题。均不是官方真题，模考分数不能预测正式成绩。

官方依据：[2026 科目三考试大纲](https://www.amac.org.cn/xwfb/tzgg/202606/P020260630399995526911.pdf)、[2026 科目一考试大纲](https://www.amac.org.cn/xwfb/tzgg/202606/P020260630399995319242.pdf)。正式考试每科100题、120分钟；本站科目三现可抽取一套100题模拟卷。

运行：`npm ci && npm run dev`。构建：`npm run build`。GitHub Pages 工作流位于 `.github/workflows`。

本项目仅供学习，不提供职业资格或个税扣除资格认定。

出题参考：公开的[模拟题题型示例](https://m.233.com/jjcy/zhinan/202512/04104837121304.html)及[章节练习目录](https://www.233.com/jjcy/moniti/index.html)。本站科目三题干、选项和解析为自行编写，未批量转载第三方题库。

科目一来源说明：来自本机 2026-10-14 的旧 `fund-practice` 项目。原始 `questions_source.json` 中 985 道科目一题带有“模考金题”“临考押题”“真题2025-05”“真题2026-05”等类别标签，但没有题目来源网址、出版信息或授权信息，因此这些标签不能视为真题来源证明。本站统一标注“来源待核验”。

访问门禁沿用本机旧版的前端密码，仅用于避免误入；GitHub Pages 是公开静态站点，前端密码不构成真正的访问控制。
