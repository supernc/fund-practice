# 基金从业资格考试练习站（科目一＋科目三）

基于本人 [tccp-practice](https://github.com/supernc/tccp-practice) 架构改造。科目一保留本机旧题 985 道，**尚未按2026大纲逐题复核**；科目三新增 38 道按 2026 年大纲原创的概念练习题。均不是官方真题，模考分数不能预测正式成绩。

官方依据：[2026 科目三考试大纲](https://www.amac.org.cn/xwfb/tzgg/202606/P020260630399995526911.pdf)、[2026 科目一考试大纲](https://www.amac.org.cn/xwfb/tzgg/202606/P020260630399995319242.pdf)。正式考试每科100题、120分钟；本站现有科目三题量不足一套完整试卷，站内为30题自测。

运行：`npm ci && npm run dev`。构建：`npm run build`。GitHub Pages 工作流位于 `.github/workflows`。

本项目仅供学习，不提供职业资格或个税扣除资格认定。
