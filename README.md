# 基金从业资格考试练习站（科目一＋科目三）

[打开网页版](https://supernc.github.io/fund-practice/#/) · [题库说明](https://supernc.github.io/fund-practice/#/bank)

题库版本 **2026.11.03**，规则核对日期 **2026-11-03**。科目一《基金基础知识与法律法规》127道，科目三《私募股权投资基金基础知识》136道，共263道原创模拟题。每题附解析、官方考点或规则链接与核对日期。每科支持100题、120分钟自测。

## 本次替换

旧科目一985道题缺少可核验出处，且发现私募信披旧口径、已废止规则和解析口径混用，已退出当前题库，由按2026大纲重编的127题替换。不是认定每一道旧题都过时，而是停止把无法确认版本的旧题混入默认练习。旧版本可在Git历史中追溯。

科目三原110道基础概念题保留，补充12道2026信披新规题及14道估值、收益计算题。大纲链接用于定位考点，不代表大纲逐字给出每个题目答案；具体法规题另外引用相应条款。题目未经考试主办方审定，覆盖各章但不穷尽考点。

新规则重点包含：

- [2026版科目一、二、三考试大纲](https://www.amac.org.cn/fwdt/wyb/rygl/cyks/cyksjcdg/jcksdg/202606/t20260630_27896.html)
- [2026私募投资基金信息披露实施细则](https://www.amac.org.cn/xwfb/tzgg/202606/P020260605683618804893.pdf)，2026-09-01施行
- [2026基金管理公司绩效考核管理指引](https://www.amac.org.cn/xwfb/xhyw/202604/P020260417619131260676.pdf)，替代2022旧指引
- [2024修订反洗钱法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2025/art_cfcc31edf0a64744bb5d7ff1307c0356.html)，2025年施行
- [2025修订反不正当竞争法](https://www.spp.gov.cn/tt/202506/t20250627_699860.shtml)，2025-10-15施行

[本次核查记录](docs/bank-review-2026-11-03.md)列出具体旧题问题；`src/data/bank-manifest.json`列出版本、数量和全部官方依据。网络检索参考了近期公开题库的分类与题型，未批量复制第三方付费题库。

## 功能与数据

沿用本人[tccp-practice](https://github.com/supernc/tccp-practice)架构，提供章节练习、随机自测、计算题、错题本、收藏和学习统计。学习记录保存在当前浏览器，可通过数据管理导出导入，不自动跨设备同步。旧题答题历史保留，新科目一使用全新ID，避免错误绑定；更新后重新开始未完成的模考。

登录门禁沿用原设置。它是公开静态网页中的简易前端门禁，不构成服务端身份认证。

## 运行和验证

```sh
npm ci
npm run validate:bank
npm run dev
npm run build
```

构建前自动校验题目ID、重复题干、选项、答案、章节、依据链接、版本日期，并回归检查本次修复的信披期限、薪酬权重和计算题。GitHub Pages工作流位于`.github/workflows/deploy.yml`。
