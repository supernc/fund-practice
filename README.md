## 本次替换

旧科目一985道题缺少可核验出处，且发现私募信披旧口径、已废止规则和解析口径混用，已退出当前题库，由按2026大纲重编的模拟题替换。不是认定每一道旧题都过时，而是停止把无法确认版本的旧题混入默认练习。旧版本可在Git历史中追溯。

科目三原110道基础概念题保留，补充12道2026信披新规题及14道估值、收益计算题。大纲链接用于定位考点，不代表大纲逐字给出每个题目答案；具体法规题另外引用相应条款。题目未经考试主办方审定，覆盖各章但不穷尽考点。

## 功能与数据

沿用本人[tccp-practice](https://github.com/supernc/tccp-practice)架构，提供章节练习、随机自测、计算题、错题本、收藏和学习统计。学习记录保存在当前浏览器，可通过数据管理导出导入，不自动跨设备同步。旧题答题历史保留，新科目一使用全新ID，避免错误绑定；更新后重新开始未完成的模考。

登录门禁沿用原设置。它是公开静态网页中的简易前端门禁，不构成服务端身份认证。

## 运行和验证

```sh
npm ci
npm run validate:bank
npm run dev
npm run build
```

构建前自动校验题目ID、重复题干、选项、答案、章节、依据链接、版本日期，并回归检查本次修复的信披期限、薪酬权重和计算题。GitHub Pages工作流位于`.github/workflows/deploy.yml`。

## 1800题扩充（2026-11-03）

| 科目 | 普通、情景与计算题 | 多考点组合辨析 | 合计 |
| --- | ---: | ---: | ---: |
| 一 | 195 | 805 | 1000 |
| 三 | 245 | 555 | 800 |

全部题目进入日常练习和随机模考，不单独预留300题。1800为题目数量，不是1800个独立考点。综合题每题包含同章四条不同基础问答，逐条判断答复正误；每个四题集合仅使用一次，考点仍会在不同组合中复现。不能把组合数量等同于独立基础题数量。网页提供类别筛选，便于先掌握基础与情景应用，再做综合辨析。

普通题输入保存在`scripts/data/foundation-subject*.json`与`extra-items.tsv`，由本次编写的147道情景/应用题及30道计算题扩充。生成方法位于`scripts/expand-bank.mjs`，用`npm run generate:bank`复现；不会仅更换人名或数字生成同一题。组合题元数据保留基础题ID、拟答选项和正误，可自动独立复算答案。

默认模考从全部题中选75道普通与情景题、25道组合题，尽量避免卷内同一基础问答重复出现。这是练习设计，不是官方题型比例；删除大量题目后可用题不足时会从其余可用题补齐。`npm run test:exam`验证100题、科目隔离、无重复及小题池情况。
